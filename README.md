# Kitchen Service Pro

GitHub Pages / PWA-ready Central Kitchen Management System.

## Upload
Upload all files to the root of a GitHub Pages repository:
- index.html
- manifest.json
- service-worker.js
- icon-192.png
- icon-512.png

Then open the GitHub Pages URL in Chrome and use **Add to Home screen / Install app**.

Default login PINs:
- Admin: 1234
- Manager: 2222
- Supervisor: 3333
- Staff: 4444

This build is browser-local and works offline. Use Admin → Backup regularly.
